# 06. 아이디어 검증 카드 (solo-biz-idea-finder 스킬 적용)

> 사용자가 이미 아이템을 정했으므로 Phase 0-C로 진입, 발굴이 아니라 **자기 반박** 용도로 15항목을 채운다. 통과 못 한 항목은 숨기지 않는다.

## 온다 — 한국 2030 게이 텍스트 커뮤니티

1. **실패 장면** — 28세 직장인이 밤 11시 Jack'd를 켠다. "얼굴", "몸 사진" 요청 3개. 앱을 지운다. 이반시티에 들어가니 메인에 마사지 광고와 4050 게시판. X를 열어 커밍아웃 스레드를 읽지만 본계정이라 답글을 못 단다. 아무 데도 말 못 하고 잔다.
2. **실패 유형 분해** — ① 만남 외 대화 공간 부재 ② 익명이면서 검증된 공간 부재 ③ 아웃팅 공포 ④ 세대 불일치(4050 플랫폼) ⑤ 카카오 등 메인스트림 플랫폼의 제한 ⑥ 자기수용 콘텐츠의 한국어 부재. **①+②+⑥을 고른다.** ③은 설계 원칙으로, ④는 포지셔닝으로 흡수. ⑤는 우리가 못 푼다.
3. **왜 지금** — (a) 2024~25 이반시티 나이 공개 전환으로 2030 이탈 가속·불만 표면화 (b) 2023 카카오 오픈채팅 성소수자 방 제한 (c) 2025 한국리서치 수용도 역대 최고·비판도 급증(양극화 = 안전한 공간 수요 증가) (d) Grindr 2025 실적이 보여준 "욕망 그리드"의 상업적 극단화와 그 피로. 2023년에도 떠올릴 수 있는 아이디어였다는 점은 인정 — **2023년 테스트 약함**.
4. **타겟** — 만 20~34세 수도권 게이·양성애 남성, 클로짓/부분 커밍아웃, 만남 앱 경험자.
5. **정량 고통** — 돈으로 환산 불가(소비자·정서 문제). **돈 필터 미통과.** 대신 정신건강 지표(우울·자살사고 유병률 일반 인구 대비 현저히 높음)가 고통의 증거.
6. **현재 땜질** — X 부계정, 오픈채팅, 디스코드, 이반시티 익명게시판, 그냥 포기. "어찌저찌 되고 있다"에 가까움 → **비타민 위험**. 다만 "X 부계정·오픈채팅"은 아웃팅·검색불가·흘러감 문제로 진통제 수요가 남아 있는지 실험으로 확인해야 함.
7. **문제 적중도** — 인지(마인드셋 콘텐츠) / 진단(주제별 스토리) / 해결 일부(소모임). 3층 모두 건드림. 해결층의 "실제 관계"는 v0.2 이후.
8. **화면 3개 MVP** — ① 홈: 오늘의 마인드셋 + 글 목록 ② 글 상세: 본문·댓글·나도·신고 ③ 글쓰기(주제·익명 옵션). + 가입 화면.
9. **첫 고객 10명 채널** — X 게이 커뮤니티(마인드셋 카드 계정), 게이코리아 익명게시판, 대학 성소수자 동아리(서울대 QIS, 연세 컴투게더 등), 다움·친구사이 청년 프로그램.
10. **시장 크기와 수익**

    | 항목 | 값 | 출처 |
    |---|---|---|
    | 모집단 | 2030 게이·양성애 남성 19~25만 | 내가 가정함(인구×3~4%) |
    | 도달 가능 모수 | 2만 | 내가 가정함(온라인 활성 10%) |
    | 객단가 | 월 3,900원 | 내가 가정함(Cade $1 Discord·국내 멤버십 관행) |
    | 필요 고객 수 | 3,590명 | 계산 |
    | 필요 침투율 | 18% | 계산 → **불가능 구간** |
    | 천장(모수 전부) | 월 7,800만 원 | 계산 |
    | 고객당 원가 | 월 10원 미만 | 인프라 $10/월 ÷ 1,000명 |

    - 12개월 후: 보수 월 20만 원(유료 50명) / 기본 월 100만 원(250명) / 낙관 월 400만 원(1,000명). 가르는 조건: 초대 바이럴 계수와 X 카드 계정 성장.
    - 글로벌로 곱해지는가: **아니오**. 한국어·한국 압력 구조에 특화. 단, 일본·대만 동아시아권 복제는 가능.
11. **경쟁 지형** — `docs/03` 참조. 한 문장: 데이팅 앱은 그리드가 매출이라 못 하고, 이반시티는 4050·광고주와 이해충돌이라 못 한다. 기존 앱이 "텍스트 게시판"을 붙이는 데는 몇 주면 충분 → 기능은 해자가 아님.
12. **방어선** — 주말 복제 가능: **예**. 쌓이는 해자: **유통 장악(2030 게이가 모이는 좁은 창구) + 데이터 축적(한국어 커밍아웃·가족·군대 스토리 아카이브, 검색 가능)**. 해자 형성까지 약 6개월, 활성 1,000명.
13. **죽는 조건 실험** — 사다리 1칸: X에 마인드셋 카드+익명 폼 2주. 응답 50건 미만이면 폐기.
14. **지속 조건**

    | 조건 | 판정 | 근거/우회 |
    |---|---|---|
    | C1 반복성 | 매일 | 커뮤니티 |
    | C2 셀프서브 | 불확실 | 국내 2030 남성의 소액 정기결제 습관은 있음(유튜브 멤버십·웹툰). 성소수자 서비스에 카드를 긁는 것에 대한 아웃팅 공포는 확인 필요 → 카드 명세서 표기명 중립화 |
    | C3 플랫폼 리스크 | 감수 가능 | 웹 우선. 앱스토어·카카오에 의존 안 함 |
    | C4 AI 독립성 | 해당 없음 | AI 없는 제품. 추후 모더레이션 보조에만 |
    | C5 확장성 | 월 30분 초과 위험 | 신고·감정노동. 자동화+자원봉사 모더레이터 필수 |
    | C6 해자 | 주말 복제 가능 + 유통·데이터 해자 | 6개월/1,000명 |
    | C7 도메인 접근권 | 확인 필요 | 사용자 본인이 당사자인지, 현업(2030 게이) 5명에 2주 내 닿는 경로가 있는지 답해야 함 |
15. **PMF 판정** — 한국: **모르겠다** (수요는 강하나 지불 의사·"비타민" 여부 미검증). 글로벌: 없다.

## 폐기한 인접 아이디어

| 아이디어 | 폐기 사유 |
|---|---|
| 게이 데이팅 앱(더 안전한 Grindr) | 정면 대결 + 원칙 위반 + 양면 마켓 |
| 성소수자 상담 매칭 플랫폼 | 양면 마켓 + 의료 인접 규제 |
| 한국어 마인드셋 팟캐스트만 | 제품이 아니라 채널. 단, 죽는 조건 실험의 결과에 따라 이것이 정답일 수 있음 |
| 게이 프렌들리 업소 지도 | 한 화면 흡수(이반시티·게이코리아에 이미 있음) |

## 결론
아이디어 스킬 기준으로는 **돈 필터·2023년 테스트·비타민 위험에서 약하다.** 그럼에도 만드는 이유는 (1) 사용자가 이미 결정했고 (2) 정지 내성·인프라 비용·C3가 좋아 실패 비용이 극히 낮으며 (3) 실험이 2주면 끝나기 때문이다. **먼저 §13 실험을 하고, 그다음 배포하라.**
