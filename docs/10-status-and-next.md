| 항목 | 왜 | 어떻게 풀리나 |

### 여기서 반드시 알아야 할 것

**이 레포는 실제 Jev 를 한 번도 호출한 적이 없다.** 지금까지의 모든 판정 관련 검증은
`scripts/qa/fake-jev.mjs` — 제가 만든 **규칙 기반 로컬 스텁**으로 했습니다.

```
TYPESAFE_API_KEY=test                        ← 아무 문자열. 진짜 키가 아님
TYPESAFE_BASE_URL=http://127.0.0.1:4141      ← 내 컴퓨터의 가짜 서버
```

- `api.typesafe.ai` 로는 요청이 나간 적이 없다 (이 환경에서는 접근도 차단돼 있다)
- 가짜 서버를 끄면 `npm run browse` 는 즉시 `error` 로 끝난다 — 스텁이 답하고 있었다는 증거
- 따라서 **검증된 것은 배선과 루프**(요청 형태, 임계치 분기, fail-open, 브라우저 결정 루프)이고,
  **검증되지 않은 것은 판정 품질**이다
- `npm run calibrate` 의 숫자도 스텁의 것이다. 리포트 헤더에 프로바이더가 찍히니 확인할 것

키를 받으면 같은 명령을 환경변수만 바꿔 다시 돌리면 된다. 코드는 그대로다.

## 3. 남은 것과 하는 법

### A. 배포 전에 반드시 — 2주 수요 실험
**이게 제품보다 먼저다.** `docs/05` §8.

1. X 계정을 만들고 `npm run cards` 로 만든 마인드셋 카드 30장을 매일 예약 발행
2. 각 카드에 익명 폼(Tally 등) 링크를 단다: "당신의 이야기를 한 문단으로"
3. 2주 뒤 응답을 센다

**판정 기준**: 50건 미만이면 제품을 열지 말고 콘텐츠 채널(X + 뉴스레터)로 축소한다. 이 판정을 미루는 것이 가장 비싼 실수다.

### B. 판정 임계치 재보정 (키를 받은 뒤)
```bash
export TYPESAFE_API_KEY=ts_...      # 또는 OPENROUTER_API_KEY
npm run calibrate                    # → calibration.md
```
리포트의 권장 임계치를 `lib/jev.ts` 의 `BLOCK_THRESHOLD`·`CRISIS_THRESHOLD` 에 반영한다.

**오차단 목록을 먼저 본다.** 임계치보다 `MOD_CATEGORIES` 의 설명 문장을 고치는 게 먼저다.

운영 시작 후 실제 글 100건을 라벨해 `fixtures/moderation-cases.jsonl` 에 추가하고 다시 돌린다. 어려운 음성 사례(차단하면 안 되는 글)를 꼭 넣는다.

### C. 배포
`docs/stack-recommendation.md` 대로.
```bash
# 1. 서울 리전 VPS + Coolify
# 2. .env 설정 — SESSION_SECRET 은 반드시 새로 만든다
openssl rand -base64 48
# 3. Postgres 로 전환: prisma/schema.prisma 의 provider 와 DATABASE_URL
# 4. 운영 DB 시드 (마인드셋만, 데모 데이터 없음)
npm run db:seed
npm run grant:mod <당신의닉네임> admin
```
**주의**: `npm run db:reset` 은 로컬 전용이다. 데모 계정과 예시 글이 들어간다.

### D. 초대코드 (v0.2)
첫 100명을 손으로 뽑기 위해 필요하다. 스키마에 `Invite` 모델을 추가하고 가입 폼에 코드 입력을 붙인다.

### E. 허깅페이스 2차 의견 (선택)
```bash
pip install fastapi uvicorn transformers torch
MODEL=<kor_unsmile 계열 모델> uvicorn scripts.ml.unsmile_server:app --port 8787
# .env
HF_MODERATION_URL="http://127.0.0.1:8787/"
```
**모델 카드에서 라이선스를 반드시 확인한다.** `docs/07` §2 의 오탐 주의사항도 읽는다.

### F. "비슷한 이야기" 임베딩 (선택)
지금은 문자 바이그램으로 동작한다. 품질을 올리려면 KURE-v1 등을 서빙하고 `EMBEDDINGS_URL` 을 설정한다.

### G. 사람이 필요한 것
도구로 해결되지 않는다.
- **당사자 커뮤니티 리드 영입** — 창업자가 당사자가 아니라면 필수다. 이 제품은 서사의 진정성이 곧 제품이다
- **모더레이터 3~5명** — 초기 3개월 모든 글에 첫 댓글이 달리게 하려면
- **커뮤니티 약속 문구 검토** — 당사자 3명에게 읽혀본다
- **법률 검토** — 민감정보 처리, 청소년보호법
