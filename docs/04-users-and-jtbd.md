# 04. 사용자·페르소나·JTBD

## 1. 핵심 타겟
**만 20~34세, 한국 거주, 게이/양성애 남성, 오프라인에서는 클로짓이거나 부분 커밍아웃 상태, 만남 앱은 써봤지만 "이야기할 곳"이 없는 사람.** 초기 1,000명은 서울·수도권 대학생/사회초년생.

## 2. 페르소나

### P1. "익명으로 처음 말해보는" 지훈 (22, 대학생, 지방→서울)
- 상황: 아무에게도 말 안 함. X에서 눈팅만. 게이 앱은 무서워서 깔았다 지움.
- JTBD: *"내가 이상한 게 아니라는 걸 확인하고, 아무도 나를 모르는 곳에서 한 번 말해보고 싶다."*
- 실패 장면: 밤 1시, X에서 커밍아웃 스레드를 읽다가 답글을 달고 싶은데 계정이 본계정이라 못 단다. 부계정을 만들려니 전화번호가 걸린다. 결국 창을 닫는다.
- 성공 지표: 가입 후 7일 내 첫 글 또는 첫 댓글.

### P2. "만남 앱에 지친" 민재 (28, 직장인, 서울)
- 상황: Grindr·Jack'd 5년. 얼굴·몸 위계에 지침. 친구는 있지만 전부 "게이 친구=술·클럽".
- JTBD: *"욕망의 대상이 아니어도 괜찮은, 나를 사람으로 대하는 게이 공간이 필요하다."* (Cade의 "If I'm not desired, I'm not valuable" 정확히 해당)
- 실패 장면: 퇴근 후 앱을 켰다가 "얼굴 보내줘"에 지쳐 삭제. 이반시티에 가보니 40대 광고와 유흥업소 배너. 게이코리아는 2010년대 UI. 다시 X로.
- 성공 지표: 주 3회 이상 방문, 소모임 1개 참여.

### P3. "가족 문제가 닥친" 성우 (31, 직장인, 결혼 압박)
- 상황: 부모가 선을 잡음. 커밍아웃할지 위장결혼할지 고민.
- JTBD: *"나와 같은 결정을 먼저 한 사람들의 결과를 알고 싶다."*
- 실패 장면: 네이버·구글에 "게이 부모 커밍아웃 후기"를 검색 → 기사와 혐오 댓글만. 이반시티 검색은 로그인 벽 + 오래된 글.
- 성공 지표: 검색 유입 → 스토리 열람 → 가입.

## 3. 반(反)페르소나 (초기에 명시적으로 배제)
- 만남·즉석 섹스 목적 사용자 → 프로필 그리드·거리순·사진 DM을 제공하지 않아 자연 이탈
- 40대 이상 → 배제가 아니라 "2030 우선" 포지셔닝. 나이 사칭 방지를 위해 가입 시 출생연도 고정(수정 불가)
- 혐오 유입(일베 등) → 가입 단계 + 신규 계정 글쓰기 대기시간 + 신고 임계치 자동 숨김

## 4. 사용자 여정과 MVP 화면 매핑

| 단계 | 사용자 행동 | MVP 화면 |
|---|---|---|
| 발견 | 검색/X 공유 링크로 "오늘의 마인드셋" 카드 도착 | `/` 랜딩(비로그인 열람 가능한 큐레이션 + 마인드셋) |
| 첫 방문 | 글 읽기(비로그인 허용) | `/posts`, `/posts/[id]` |
| 전환 | 닉네임+비밀번호만으로 가입 | `/join` |
| 첫 행동 | 공감 누르기 → 댓글 → 글 | 글 상세의 공감/댓글, `/write` |
| 습관 | 주제 필터, 오늘의 질문 | 홈 상단 "오늘의 마인드셋", 주제 탭 |
| 소속 | 소모임 보기 | `/groups` (v0.2) |
