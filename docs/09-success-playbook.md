# 09. 성공 플레이북 — 온다를 어떻게 성공시키고, 도구로 어떻게 품질을 올리나

> 이 문서는 조사(01~08)를 바탕으로 한 **의견**이다. 숫자 목표는 `내가 가정함`이며, 2주 실험 결과로 갈아끼운다.

## 0. "성공"의 정의를 먼저 바꾼다
한국 2030 게이 텍스트 커뮤니티는 "회원 48만"으로 성공하지 않는다. 그 길은 이반시티가 이미 갔고, 그 끝은 광고와 세대 이탈이었다. 온다의 성공은 세 숫자다.

| 지표 | 6개월 목표 | 이유 |
|---|---|---|
| 주간 작성자 수(글+댓글) | 300명 | "읽는 사람"이 아니라 "말하는 사람"이 공동체다 |
| 30일 재방문율 | 40% | 리추얼이 작동하는지의 증거 |
| 아웃팅·신상 사고 | 0건 | 한 번이면 끝난다. 신뢰가 곧 성장 엔진 |

## 1. 성공 원칙 5가지 (GayUnmasked에서 배운 것 + 한국 조건)

1. **콘텐츠가 먼저, 커뮤니티는 나중.** Sigurd는 숏폼 → 커뮤니티 순서였다. 온다는 X(트위터)에 "오늘의 마인드셋" 카드를 30일간 매일 올리고 익명 폼을 단다. 응답 50건이 안 되면 제품을 열지 않는다(`docs/05` §8).
2. **첫 100명은 손으로 뽑는다.** 초대코드로만 가입. 대학 성소수자 동아리, 다움·친구사이 청년 프로그램, X의 글 잘 쓰는 익명 계정에게 개별 초대. 첫 100명의 글 밀도가 이후 1만 명의 문화를 정한다.
3. **리추얼이 소속감의 실체다.** 수요일 "이번 주 질문", 일요일 "회고", 월 1회 텍스트 AMA(먼저 지나간 사람 1명). Sigurd의 주 2회 콜의 텍스트 버전.
4. **안전이 브랜드다.** 이메일·전화·사진 미수집, 즉시 탈퇴, 신고 24시간 처리, 아웃팅 즉시 영구정지. 이 다섯을 랜딩페이지 첫 화면에 쓴다. 이반시티가 못 하는 약속이다.
5. **창업자는 큐레이터이자 첫 답변자다.** 초기 3개월은 모든 글에 첫 댓글이 달리게 한다(직접 또는 모더레이터 5명). 답 없는 첫 글이 이탈의 1순위 원인이다. 단, 창업자가 당사자가 아니라면 당사자 커뮤니티 리드를 반드시 영입한다.

## 2. 90일 실행 순서

| 주차 | 할 일 | 도구 |

## 3. 도구별 품질 향상 지도

## 4. 하지 말 것 (실패 경로)
- 데이팅 기능 추가 — 원칙 붕괴, 이반시티 2호
- 초기부터 광고 — 신뢰 붕괴
- 카카오·앱스토어 의존 — 플랫폼 검열 리스크
- Jev 답을 임계치 없이 실행 — 오탐 5%가 곧 사용자 이탈
- 창업자가 모든 글에 영원히 답하기 — 3개월 후 번아웃. 모더레이터와 "나도"로 이양

## 4-1. 지표를 어디서 보나

`/mod/stats` (운영자 전용) — 이번 주 작성자 수를 맨 위에 크게 두고, 12주 추이, 꾸준함, 검토 대기,
답 없는 글, 아웃팅 판정, 주제별 분포를 한 화면에 둔다. 터미널에서는 `npm run metrics`.
전부 우리 DB 에서 계산하므로 쿠키도, 외부 전송도, 개인 식별자도 없다. 외부 분석 도구는 환경변수를
넣을 때만 켜지고 기본은 꺼져 있다.

## 5. 3개월 뒤 판정 기준
주간 작성자 100명 미만이면 제품이 아니라 **콘텐츠 채널(X 카드 + 뉴스레터)로 축소**한다. 100명 이상이면 소모임·오프라인으로 확장한다. 이 판정을 미루는 것이 가장 비싼 실수다.
