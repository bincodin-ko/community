### (c) 지원·상담 층 — 협력 대상
띵동(청소년), 친구사이, 다움, 성소수자부모모임. 비영리·후원 모델. 콘텐츠·상담 연계 파트너.

**앱스토어 검색 기록**: Google Play/App Store에서 "게이 커뮤니티", "이반시티", "탑지"로 검색 → 이반시티·탑지·Jack'd·Grindr·Blued 확인. **"게이 마인드셋", "커밍아웃 커뮤니티", "퀴어 익명 게시판"으로는 한국어 앱 없음.** (단, 이 환경에서 스토어 페이지 직접 열람은 차단되어 설치 수·최신 리뷰 20개는 확인 못 함 — 사용자 확인 필요.)

### 왜 기존 강자가 이걸 안 하는가 (한 문장)
데이팅 앱은 **매출이 "욕망의 그리드"에서 나오기 때문에** 그리드를 치우는 제품을 만들 수 없고, 이반시티는 **4050 유료 광고주·기존 회원과의 이해충돌** 때문에 2030 전용으로 갈아엎지 못한다.

## 3. 바닥의 소리 (아픔의 증거)

원문 접근이 차단되어 **직접 인용은 확보하지 못했다**(아이디어 스킬 기준 미통과 항목). 2차 자료(나무위키·게이코리아 게시글 제목·앱 리뷰 요약)에서 반복 확인되는 불만:

1. "이반시티는 중년시티" — 2030이 대거 이탈했고 불만이 누적됨 (게이코리아 익명게시판 글 제목 "누군가 게이의 미래를 묻거든, 이반시티를 보게 하라")
2. 40~50대가 20~30대로 나이 사칭, 사진 도용, 거절 후 치근댐
3. 메인이 유흥업소·불법 마사지·호스트바 광고
4. 앱 오류 지속, 탈퇴가 안 됨 ("이반시티 탈퇴 왜케 안시켜줌??")
5. 카카오 오픈채팅 성소수자 방 기능 제한
6. 2011·2012년 위장가입 → 사진 수집 → 외모 순위·신상 공개 사건 → 이후 커뮤니티들이 가입인증제로 전환

**죽는 조건 실험(검증 사다리 1칸)에서 반드시 확인할 것**: 게이코리아 익명게시판, X, 디시 게이갤러리 등에서 "만남 말고 이야기할 곳이 없다"류의 발화가 실제로 반복되는지 원문 5개 이상 인용.

## 4. 문제 3층 분해

| 층 | 내용 | 기존 제품이 덮나 |
|---|---|---|
| 인지층 | "내가 느끼는 수치심이 주입된 것"임을 모른다. 문제를 "나"로 둔다 | 아무도 안 덮음 (해외 크리에이터 영어 콘텐츠만) |
| 진단층 | 커밍아웃/가족/군대/회사 중 내 상황에 뭐가 해당되는지, 남들은 어떻게 했는지 모른다 | X·이반시티에 파편적으로 존재, 검색·정리 불가 |
| 해결층 | 실제로 말할 사람, 소속될 곳, 오프라인으로 이어질 관계가 없다 | 만남 앱이 "섹스/연애"로만 덮음. 친구·동료 관계는 공백 |

우리 제품은 인지층(오늘의 마인드셋·큐레이션 글) + 진단층(주제별 스토리 게시판·검색) + 해결층 일부(소모임·그룹 대화)를 덮는다. 세 층을 다 건드리되 대상은 "2030 게이 남성·텍스트"로 좁힌다.
