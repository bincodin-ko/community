# 05. 제품 전략 — 온다(ONDA)

> 이름은 가칭. "(마음이) 온다 · (누군가) 온다 · (아침이) 온다". 사용자가 바꿔도 코드에는 `APP_NAME` 하나만 바꾸면 된다.

## 1. 한 문장 포지셔닝
**"만남 앱이 아니라, 게이로 사는 마음을 이야기하는 곳."** — 한국 2030 게이를 위한 텍스트 우선·익명·검증 커뮤니티.

## 2. 제품 원칙 (Cade 인터뷰에서 도출)
1. **정체성은 문제가 아니다** — 첫 화면은 프로필이 아니라 이야기다.
2. **두 번째 수치심 체계를 만들지 않는다** — 얼굴 그리드·거리순·스펙 필터·사진 DM 없음. 텍스트 우선.
3. **먼저 지나간 사람을 보여준다** — "나도 그랬다" 스토리, 주제별(커밍아웃·가족·군대·회사·연애·마음).
4. **입구는 낮게, 벽은 단계적으로** — 닉네임만으로 시작, 활동·시간·초대에 따라 권한 확대.
5. **언어를 준다** — 오늘의 마인드셋(일일 한 문장 + 질문), 용어집.
6. **구조와 소속** — 주간 리추얼, 소모임, 운영자 큐레이션.
7. **아웃팅 제로** — 실명·전화번호·사진을 요구하지도 저장하지도 않는다. 캡처 방지 대신 "캡처 시 식별 불가" 설계(닉네임 주기적 변경 가능, 글 익명 옵션).

## 4. 신뢰·안전 설계 (블라인드 모델 응용)
- **분리 저장**: 인증 정보(추후 휴대폰 해시)와 활동 데이터를 다른 테이블·키로 저장. 운영자도 연결 불가.
- **가입 마찰의 단계화**: 0단계 닉네임(읽기·공감) → 1단계 24시간 경과 or 초대코드(글·댓글) → 2단계 활동 등급(소모임 개설).
- **신고 임계치**: 신고 3건 이상 자동 숨김 + 운영자 검토 큐. 신고 남용 계정 제재.
- **신규 계정 속도 제한**: 첫 24시간 글 1개·댓글 5개.
- **아웃팅 대응**: 신상 언급 글 즉시 숨김·삭제, 작성자 영구 정지. 가이드에 명시.
- **데이터 최소화**: IP는 해시 후 30일 보관. 이메일·전화·실명 미수집.
- **탈퇴 즉시**: 이반시티의 최대 불만. 설정에서 1클릭 탈퇴, 글은 "탈퇴한 사용자"로 익명화.

## 5. 수익 모델 (아이디어 스킬 기준 정직하게)

| 후보 | 판정 |
|---|---|
| 광고 | 이반시티 실패 원인. **하지 않음** |
| 데이팅 유료화 | 원칙 위반. 하지 않음 |
| **후원 멤버십** (월 3,900원, 배지·아카이브·소모임 우선) | 주 모델. Cade의 $1 Discord와 동일 논리 — 돈은 진지함 필터 |
| 소모임·오프라인 이벤트 참가비 수수료 | v0.3 |
| 앨라이 기업·상담기관 제휴 콘텐츠(표시) | 신중히, 사용자 투표로 |

**바닥 계산** (모든 값이 `내가 가정함`이므로 신뢰도 낮음):
- 도달 가능 모수: 2030 게이 남성 ~20만 중 온라인 커뮤니티 활성 10% = 2만 명
- 필요 매출 월 1,400만 원 ÷ 3,900원 = 3,590명 유료 = **모수의 18% → 사실상 불가능**
- 결론: **이 제품은 단독으로 월 1만 달러 SaaS가 되기 어렵다.** 현실적 목표는 (a) 월 100~300만 원의 자급 운영 + (b) 크리에이터·콘텐츠·이벤트로의 확장 + (c) 커뮤니티 자산을 바탕으로 한 후속 제품. 사용자는 이를 알고 시작해야 한다.
- 인프라: 고객 0~1,000명까지 월 $0~10. 마진 문제 없음.

## 8. 죽는 조건 실험 (가장 먼저 할 일)
**검증 사다리 1칸 — 미끼 도구.** 배포 전에 "오늘의 마인드셋" 카드 30개를 X 계정으로 매일 올리고, 각 카드에 "당신의 이야기" 익명 폼 링크를 단다. 2주 안에 폼 응답 50건 미만이면 "이야기할 곳" 수요 가설이 틀린 것이다. 그때는 제품을 만들지 말고 콘텐츠 채널로 축소한다.

## 9. KPI
- 북극성: **주간 글+댓글 작성자 수** (읽기만 하는 사용자 말고 말하는 사용자)
- 가드레일: 신고 24시간 내 처리율, 아웃팅 사고 0건, 탈퇴 즉시 처리율
