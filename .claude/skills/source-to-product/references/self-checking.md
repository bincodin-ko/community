# 자기 검사 붙이기

"내가 말 안 해도 알아서 고치는" 자동화는 한 층으로 안 된다. **탐색 → 판정 → 수정** 세 층이고, 각 층이 다른 도구다.

## 층 1: 편집 직후

코딩 에이전트가 파일을 고친 직후에 포매터·린터·타입체크를 돌린다. 오류를 에이전트에게 되돌려 주면 같은 턴 안에서 고친다.

- 훅 타임아웃을 실제 실행 시간보다 넉넉히 잡는다. 포매터 + 린터 + 타입체크를 연달아 돌리면 콜드 캐시에서 2분이 넘을 수 있다
- 대상 파일 확장자로 걸러 불필요한 실행을 막는다

## 층 2: 턴이 끝나려 할 때

에이전트가 "완료했습니다"라고 말하며 끝내려 할 때, **검증이 실제로 돌았는지** 확인한다.

방법: 이번 턴의 기록을 읽어 (a) 파일이 수정됐는데 (b) 그 뒤로 테스트·빌드가 돈 흔적이 없으면, 판정 모델에 몇 개 질문을 던진다.

- "이 마무리 메시지는 완료를 주장하는가"
- "수정된 파일은 자동 검증이 가능한 종류인가"
- "테스트가 실제로 실행되어 통과했다고 말하는가"

완료 주장 + 검증 없음이면 턴을 끝내지 않고 되돌려 보낸다.

**반드시 fail-open 으로 만든다.** 키가 없거나, 판정 모델이 죽었거나, 기록을 못 읽으면 **항상 통과**시킨다. 이 훅이 에이전트를 막아 세우면 개발이 멈춘다.

**한 번만 막는다.** 같은 턴에서 반복해 막으면 무한 루프가 된다.

## 층 3: 화면을 실제로 돌아다닌다

브라우저 자동화로 앱을 돌면서 세 가지를 동시에 한다.

### (a) 결정적 검사 — 모델 없이도 확실한 것

- HTTP 상태, 콘솔 오류, 실패한 요청
- 라벨 없는 입력, 빈 링크, alt 없는 이미지
- 모바일 폭에서 가로 스크롤

**프레임워크의 정상 동작을 오류로 세지 않도록 거른다.** 예: Next.js 의 링크 프리페치 취소는 정상이다. 이런 걸 안 거르면 리포트가 노이즈로 가득 차서 아무도 안 본다.

### (b) 판정 검사 — 모델이 필요한 것

화면의 텍스트 줄들을 모아 "사용자가 보면 안 되는 개발자 흔적인가"를 묻는다. TODO, 미번역 키, `undefined`, 깨진 템플릿.

### (c) 목표 기반 탐색

"가입해서 글 하나 올리기" 같은 목표를 주고, 매 단계 판정 모델이 **어느 요소를 누를지** 고르게 한다. 확신이 낮으면 멈추고 사람에게 넘긴다.

**입력 값은 모델이 만들지 않게 한다.** 픽스처가 만든다. 모델이 폼에 아무 문자열이나 넣으면 무엇이 검증됐는지 알 수 없다.

**이 층의 진짜 값은 자동 수정이 아니라 발견이다.** 판정기가 DOM 을 읽으면 사람이 못 보던 게 드러난다. 실제로 나오는 것들:
- `title` 속성이 접근성 이름을 가로채 링크가 엉뚱하게 읽히는 경우
- 화면마다 제목이 같아서 어디인지 알 수 없는 경우
- 폼 제출 후 아무 변화가 없는 경로

### 브라우저 버전 문제

브라우저 자동화 패키지가 기대하는 빌드와 환경에 설치된 빌드가 다르면 실행이 안 된다. 별도 디렉터리에 기대 버전 이름으로 심볼릭 링크를 걸면 대개 동작한다. 안 되면 **안 된다고 적고** 대체 경로(직접 만든 QA 워크)를 쓴다.

## 층 0: 커밋 직전

두 갈래로 나눈다.

- **결정적 검사는 커밋을 막는다(fail-closed)**: API 키·개인키 패턴, `.env` 파일, 제품 코드의 디버그 잔재
- **판정 검사는 경고만 한다(fail-open)**: 커밋 메시지가 변경 내용과 맞는지

주의할 것:
- **파일 이름을 셸 문자열에 넣지 않는다.** 인자 배열로 넘긴다
- **키 패턴은 서비스별로 쓴다.** 뭉뚱그린 정규식은 정작 실제 형식을 못 잡는다
- **커밋 메시지는 `commit-msg` 단계에서 읽는다.** `pre-commit` 단계에서는 아직 새 메시지가 없어서 이전 커밋 메시지를 비교하게 된다
- **자기 자신을 막지 않는지 확인한다.** 디버그 잔재 검사가 로그를 출력하는 게 정상인 스크립트까지 막으면, 그 파일을 영영 커밋할 수 없다

## CI

푸시·PR·매일 밤에 전부 돌린다. 키가 없으므로 **가짜 판정 서버**를 띄워 루프를 돌린다.

- 서버가 뜰 때까지 기다리는 루프는 **실패하면 실패로 끝낸다.** 조용히 넘어가면 다음 단계에서 연결 거부만 보이고 원인은 안 보인다
- 서버 로그를 아티팩트로 남긴다
- QA 리포트를 아티팩트로 올린다

## 사람이 남는 자리

이 전부를 붙여도 사람이 남는 곳이 있다. 그걸 명시한다.

- PR 승인
- 판정기가 "불확실"로 멈춘 케이스
- 임계치 재보정

이걸 없애면 오답 5%가 그대로 배포된다.
